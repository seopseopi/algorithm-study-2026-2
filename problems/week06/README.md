# 6주차 공통 문제

- 활동일: 2026-11-09
- 문제: 1744. 수 묶기
- 백준 문제 주소: https://www.acmicpc.net/problem/1744
- 난이도: Gold IV
- 학습 주제: 정렬, 탐욕적 알고리즘

## 학습 목표

수의 부호와 크기에 따라 선택 기준을 나누고, 각 선택이 전체 합을 최대화하는 이유를 설명합니다.

## 문제

정수 `N`개로 이루어진 수열이 있습니다. 서로 다른 위치에 있는 두 수를 묶으면 두 수의 곱이 합계에 더해지고, 묶지 않은 수는 그대로 더해집니다. 각 수는 최대 한 번만 묶을 수 있습니다.

수를 적절하게 묶었을 때 얻을 수 있는 합계의 최댓값을 구하세요. 수열에서 서로 떨어진 위치에 있는 두 수를 묶어도 됩니다.

## 입력

첫째 줄에 수열의 크기 `N`이 주어집니다. 다음 `N`개 줄에는 수열의 각 정수가 하나씩 주어집니다.

## 출력

가능한 합계의 최댓값을 출력합니다.

## 제한

- `1 ≤ N < 50`
- 각 수는 `-1,000` 이상 `1,000` 이하의 정수입니다.
- 정답은 `2³¹`보다 작습니다.

## 예제

입력:

```text
6
-3
-2
0
1
2
4
```

출력:

```text
15
```

`-3`과 `-2`, `2`와 `4`를 각각 묶고 `0`과 `1`을 그대로 더하면 `6 + 8 + 0 + 1 = 15`입니다.

## 과목 수준에 적합한 이유

두 수를 곱할 때와 더할 때의 결과를 비교해야 하며, 음수와 0, 1을 각각 다르게 다루어야 합니다. 정렬을 활용한 탐욕적 선택을 설계하고 그 근거를 설명하는 연습에 적합합니다.

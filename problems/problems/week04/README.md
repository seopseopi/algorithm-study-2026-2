# 4주차 공통 문제

- 활동일: 2026-10-26
- 문제: 1931. 회의실 배정
- 백준 문제 주소: https://www.acmicpc.net/problem/1931
- 난이도: Gold V
- 학습 주제: 정렬, 탐욕적 알고리즘

## 학습 목표

여러 선택 기준을 비교하고, 탐욕적으로 선택한 결과가 최적인 이유를 설명하는 연습을 합니다.

## 문제

하나의 회의실을 사용하려는 N개의 회의가 있습니다. 각 회의의 시작 시간과 종료 시간이 주어질 때, 시간이 겹치지 않도록 회의를 골라 회의실을 사용할 수 있는 회의의 최대 개수를 구하세요.

한 회의가 끝나는 시간에 다른 회의를 바로 시작할 수 있습니다. 회의의 시작 시간과 종료 시간이 같을 수도 있습니다.

## 입력

첫째 줄에 회의의 수 N이 주어집니다. 다음 N개 줄에는 각 회의의 시작 시간과 종료 시간이 공백으로 구분되어 주어집니다.

## 출력

회의실에서 진행할 수 있는 회의의 최대 개수를 출력합니다.

## 제한

- 1 ≤ N ≤ 100,000
- 시작 시간과 종료 시간은 0 이상 2³¹ - 1 이하인 정수입니다.
- 각 회의의 시작 시간은 종료 시간보다 늦지 않습니다.
- 시간 제한: 2초
- 메모리 제한: 128MB

## 예제

입력:
```
5
1 4
3 5
4 6
6 6
6 8
```

출력:
```
4
```

예를 들어 (1, 4), (4, 6), (6, 6), (6, 8)을 선택할 수 있습니다.

## 과목 수준에 적합한 이유

정렬 기준에 따라 선택 결과가 달라지는 문제입니다. 탐욕적 선택의 근거를 교환 논증으로 설명하고, 종료 시간이 같은 회의와 길이가 0인 회의를 함께 고려할 수 있습니다.

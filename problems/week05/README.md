# 5주차 — 탐욕적 알고리즘과 우선순위 큐

## 공통 문제
- 백준 1715번: 카드 정렬하기
- 문제 링크: https://www.acmicpc.net/problem/1715

## 문제 요약
여러 카드 묶음을 하나로 합칠 때 필요한 총 비교 횟수의 최솟값을 구한다. 두 묶음의 크기가 A와 B라면 합치는 데 A+B번의 비교가 필요하다.

## 학습 목표
- 카드 묶음을 합치는 순서에 따라 비교 횟수가 달라지는 이유를 이해한다.
- 가장 작은 두 묶음을 먼저 합치는 탐욕적 알고리즘을 적용한다.
- 최소 힙 기반의 우선순위 큐로 최솟값을 효율적으로 관리한다.

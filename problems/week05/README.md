# 5주차 공통 문제

- 활동일: 2026-11-02
- 문제: 1715. 카드 정렬하기
- 백준 문제 주소: https://www.acmicpc.net/problem/1715
- 난이도: Gold IV
- 학습 주제: 탐욕적 알고리즘, 우선순위 큐

## 학습 목표

반복되는 선택이 전체 비용에 미치는 영향을 분석하고, 적절한 자료구조를 이용해 탐욕적 알고리즘을 효율적으로 구현합니다.

## 문제

각각 정렬된 숫자 카드 묶음 `N`개가 있습니다. 크기가 `A`와 `B`인 두 묶음을 하나로 합치려면 `A + B`번의 비교가 필요하며, 합친 묶음의 크기는 `A + B`입니다.

두 묶음씩 선택해 모든 카드를 하나의 묶음으로 만들 때, 필요한 비교 횟수의 합이 최소가 되도록 하세요. 묶음이 처음부터 하나라면 비교는 필요하지 않습니다.

## 입력

첫째 줄에 카드 묶음의 수 `N`이 주어집니다. 다음 `N`개 줄에는 각 카드 묶음의 크기가 하나씩 주어집니다.

## 출력

모든 카드 묶음을 하나로 합치는 데 필요한 최소 비교 횟수를 출력합니다.

## 제한

- `1 ≤ N ≤ 100,000`
- 각 카드 묶음의 크기는 `1` 이상 `1,000` 이하의 정수입니다.
- 시간 제한: 2초
- 메모리 제한: 128MB

## 예제

입력:

```text
4
5
10
20
30
```

출력:

```text
115
```

크기가 5와 10인 묶음을 합치면 비교 횟수는 15입니다. 이어서 15와 20을 합치고, 마지막으로 30과 35를 합치면 총 비교 횟수는 `15 + 35 + 65 = 115`입니다.

## 과목 수준에 적합한 이유

묶음을 합치는 순서에 따라 총비용이 달라지므로 탐욕적 선택이 최적인 이유를 고민할 수 있습니다. 새로 합친 묶음도 다음 선택에 포함해야 하므로 반복적으로 최솟값을 다루는 자료구조의 활용을 연습하기 좋습니다.

# 8주차 - 센서

## 문제 정보
- 문제 번호: 2212
- 문제 이름: 센서
- 난이도: Gold V
- 문제 링크: https://www.acmicpc.net/problem/2212
- 학습 주제: 그리디 알고리즘, 정렬

## 문제 설명
N개의 센서와 K개의 집중국이 주어졌을 때, 모든 센서를 수신할 수 있도록 집중국을 배치하면서 수신 가능 영역 길이의 합을 최소화하는 문제이다.

## 풀이 방법
1. 센서의 위치를 오름차순으로 정렬한다.
2. 인접한 센서 사이의 거리 차이를 계산한다.
3. 계산한 거리 차이를 정렬한다.
4. 가장 큰 거리 K-1개를 제외한다.
5. 나머지 거리의 합을 구한다.

## 시간 복잡도
- O(N log N)

## 학습 내용
센서의 위치 자체보다 센서 사이의 거리 차이에 집중하여 문제를 해결하였다. 가장 큰 간격을 기준으로 센서들을 분리하는 과정에서 그리디 알고리즘의 선택 기준을 이해할 수 있었다.

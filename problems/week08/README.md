# 8주차 공통 문제

- 활동일: 2026-11-23
- 문제: 2212. 센서
- 백준 문제 주소: https://www.acmicpc.net/problem/2212
- 난이도: Gold V
- 학습 주제: 정렬, 탐욕적 알고리즘

## 학습 목표

정렬된 위치에서 그룹을 나누는 기준을 찾고, 탐욕적으로 선택한 결과가 최적인 이유를 설명합니다.

## 문제

직선 위에 `N`개의 센서가 있습니다. 최대 `K`개의 집중국을 설치해 모든 센서가 적어도 하나의 집중국과 통신하도록 하려고 합니다. 각 집중국은 직선 위의 연속된 구간에서 신호를 받을 수 있습니다.

모든 센서를 포함하도록 수신 구간을 정할 때, 집중국별 수신 구간 길이의 합의 최솟값을 구하세요. 수신 구간의 길이는 0일 수 있으며, 여러 센서가 같은 좌표에 있을 수 있습니다.

## 입력

첫째 줄에 센서의 수 `N`, 둘째 줄에 집중국의 수 `K`가 주어집니다. 셋째 줄에는 센서의 좌표 `N`개가 공백으로 구분되어 주어집니다.

## 출력

모든 센서를 포함하는 수신 구간 길이의 합의 최솟값을 출력합니다.

## 제한

- `1 ≤ N ≤ 10,000`
- `1 ≤ K ≤ 1,000`
- 센서의 좌표는 정수이며 중복될 수 있습니다.

## 예제

입력:

```text
5
2
1 2 8 9 10
```

출력:

```text
3
```

`1`부터 `2`까지와 `8`부터 `10`까지를 각각 수신하면 길이의 합이 `1 + 2 = 3`입니다.

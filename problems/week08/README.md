# Week 08 - 그리디 알고리즘 (Greedy Algorithm)

## 1. 문제 소개

- 문제: 백준 2212번 - 센서
- 문제 링크: https://www.acmicpc.net/problem/2212
- 알고리즘: 그리디 알고리즘, 정렬
- 사용 언어: Python

## 2. 문제 설명

N개의 센서와 K개의 집중국이 주어졌을 때, 모든 센서가 적어도 하나의 집중국과 통신할 수 있도록 각 집중국의 수신 구간 길이의 합을 최소화하는 문제이다.

## 3. 해결 방법

1. 센서의 좌표를 오름차순으로 정렬한다.
2. 인접한 센서 사이의 거리(간격)를 계산한다.
3. 계산한 간격을 오름차순으로 정렬한다.
4. 가장 큰 K-1개의 간격을 제외한다.
5. 나머지 N-K개의 간격을 합산하여 최소 수신 구간 길이를 구한다.

집중국이 K개라면 센서를 최대 K개의 그룹으로 나눌 수 있다. 따라서 가장 큰 간격을 기준으로 그룹을 나누는 것이 전체 수신 구간의 길이를 최소화하는 방법이다.

## 4. 예외 처리

- 집중국의 개수가 센서의 개수 이상인 경우: 0을 출력한다.
- 센서가 동일한 좌표에 있는 경우: 인접한 센서 사이의 간격은 0이다.
- 집중국이 하나인 경우: 가장 왼쪽 센서와 가장 오른쪽 센서 사이의 거리가 정답이다.

## 5. 시간 및 공간 복잡도

| 구분 | 복잡도 |
|---|---|
| 센서 좌표 정렬 | O(N log N) |
| 인접 센서 간격 계산 | O(N) |
| 간격 정렬 | O(N log N) |
| 전체 시간 복잡도 | O(N log N) |
| 공간 복잡도 | O(N) |

## 6. 학습 내용

이번 문제를 통해 구간을 분할하는 문제를 인접한 값 사이의 간격을 선택하는 문제로 변환하여 해결하는 방법을 학습하였다. 또한 파이썬의 정렬과 리스트 슬라이싱을 활용하여 그리디 알고리즘을 효율적으로 구현하였으며, 탐욕적 선택이 전체 최적해로 이어지는 이유를 이해할 수 있었다.

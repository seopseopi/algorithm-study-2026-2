# 7주차 공통 문제

- 활동일: 2026-11-16
- 문제: 11000. 강의실 배정
- 백준 문제 주소: https://www.acmicpc.net/problem/11000
- 난이도: Gold V
- 학습 주제: 정렬, 탐욕적 알고리즘, 우선순위 큐

## 학습 목표

강의 시작 시간과 종료 시간을 비교해 강의실을 재사용하는 기준을 정하고, 우선순위 큐를 활용해 필요한 강의실의 최소 개수를 구합니다.

## 문제

여러 강의의 시작 시간과 종료 시간이 주어집니다. 한 강의실에서는 한 번에 하나의 강의만 진행할 수 있습니다. 앞 강의가 끝나는 시간에 다른 강의를 바로 시작할 수 있을 때, 모든 강의를 진행하기 위해 필요한 강의실의 최소 개수를 구하세요.

## 입력

첫째 줄에 강의의 개수 `N`이 주어집니다. 다음 `N`개 줄에는 각 강의의 시작 시간 `S`와 종료 시간 `T`가 주어집니다.

## 출력

필요한 강의실의 최소 개수를 출력합니다.

## 제한

- `1 ≤ N ≤ 200,000`
- `0 ≤ S < T ≤ 1,000,000,000`

## 예제

입력:

```text
3
1 3
2 4
3 5
```

출력:

```text
2
```

첫 강의가 끝나는 3에 세 번째 강의를 같은 강의실에서 시작할 수 있습니다. 두 번째 강의는 첫 강의와 시간이 겹치므로 강의실이 두 개 필요합니다.

## 과목 수준에 적합한 이유

강의 시작 순서대로 살펴보면서 가장 빨리 비는 강의실을 선택하는 탐욕적 기준을 설계합니다. 4주차 회의실 배정과 달리 모든 강의를 진행해야 하므로, 우선순위 큐를 이용해 여러 강의실의 종료 시간을 관리하는 연습에 적합합니다.

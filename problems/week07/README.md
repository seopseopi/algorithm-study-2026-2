# Week 07 - 강의실 배정

## 문제 정보
- 문제 번호: 11000
- 문제 이름: 강의실 배정
- 난이도: Gold V
- 알고리즘: 그리디 알고리즘, 우선순위 큐
- 문제 링크: https://www.acmicpc.net/problem/11000

## 문제 설명
N개의 강의가 주어지고, 각 강의의 시작 시간과
종료 시간이 주어진다.

모든 강의를 진행하기 위해 필요한
강의실의 최소 개수를 구하는 문제이다.

하나의 강의실에서는 동시에 두 개 이상의
강의를 진행할 수 없으며, 강의가 끝나는 시간에
다른 강의를 바로 시작할 수 있다.

## 입력
첫 번째 줄에 강의의 개수 N이 주어진다.

다음 N개의 줄에 각 강의의
시작 시간 S와 종료 시간 T가 주어진다.

## 출력
모든 강의를 진행하기 위해 필요한
강의실의 최소 개수를 출력한다.

## 예제 입력
3
1 3
2 4
3 5

## 예제 출력
2

# 5주차 — 백준 1715 카드 정렬하기

## 문제
여러 카드 묶음을 하나로 합칠 때 필요한 총 비교 횟수의 최솟값을 구한다. 두 묶음을 합칠 때는 두 묶음의 카드 수를 더한 만큼 비교가 필요하다.

## 풀이 방법
최소 힙 기반의 우선순위 큐를 사용하여 현재 가장 작은 두 묶음을 반복해서 합친다. 먼저 합친 묶음은 이후의 비교에도 다시 포함되므로 작은 묶음부터 합쳐야 전체 비교 횟수를 줄일 수 있다.

1. 모든 카드 묶음의 크기를 우선순위 큐에 넣는다.
2. 가장 작은 두 값을 꺼내 합한다.
3. 합한 값을 총 비교 횟수에 더하고, 큐에 다시 넣는다.
4. 묶음이 하나만 남을 때까지 반복한다.

## 예시
묶음의 크기가 8, 12, 15, 30인 경우:

- 8 + 12 = 20
- 15 + 20 = 35
- 30 + 35 = 65

총 비교 횟수는 20 + 35 + 65 = **120번**이다.

## 확인할 사항
- 묶음이 하나라면 합칠 필요가 없으므로 정답은 0이다.
- 새로 만들어진 묶음도 다음 최솟값 선택에 포함해야 한다.
- 최종 묶음의 크기가 아니라 매 단계의 비교 횟수를 누적해서 출력한다.
- 누적 비교 횟수는 `long long`으로 저장한다.

## 시간 복잡도
총 N-1번 합치며 우선순위 큐의 삽입과 삭제에 O(log N)이 걸리므로 **O(N log N)**이다.

## 배운 점
처음 정렬한 순서만 따르는 것이 아니라, 새로 만들어진 묶음까지 포함하여 매번 가장 작은 두 값을 선택해야 한다. 이처럼 값이 계속 추가되는 상황에서 최솟값을 반복해서 찾을 때 우선순위 큐가 유용하다는 점을 이해하였다.

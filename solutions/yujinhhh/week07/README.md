# 11000. 강의실 배정

- 문제: https://www.acmicpc.net/problem/11000
- 언어: C++17
- 코드: [11000.cpp](11000.cpp)

## 문제 분석과 풀이

각 강의는 시작 시간과 종료 시간이 주어진다. 같은 강의실에서 한 강의가 끝나는 시각에 다음 강의를 바로 시작할 수 있다. 모든 강의가 겹치지 않게 진행되도록 필요한 강의실 수의 최솟값을 구한다.

강의를 시작 시간 오름차순으로 정렬하고, 우선순위 큐에 현재 배정된 강의실들의 종료 시간을 저장한다. 우선순위 큐의 최솟값은 가장 먼저 비는 강의실의 종료 시간이다.

강의를 하나씩 확인하면서 가장 빨리 비는 강의실의 종료 시간이 현재 강의의 시작 시간 이하라면 그 강의실을 재사용한다. 그렇지 않으면 기존 강의들과 겹치므로 새 강의실이 필요하다. 현재 강의의 종료 시간을 큐에 넣는다. 모든 강의를 처리한 뒤 큐의 크기가 필요한 최소 강의실 수다.

## 정당성

강의들을 시작 시간 순으로 처리한다. 현재 강의 시작 시간보다 일찍 또는 같은 시각에 끝나는 강의실이 있으면 그중 가장 빨리 비는 강의실을 재사용할 수 있다. 이때 기존 강의실을 다시 배정하므로 강의실 수는 늘지 않는다.

가장 빨리 비는 강의실의 종료 시간조차 현재 시작 시간보다 늦다면, 다른 모든 강의실도 현재 강의와 시간이 겹친다. 따라서 기존 강의실을 사용할 수 없고 새 강의실 하나가 반드시 필요하다. 알고리즘은 이 경우에만 큐 크기를 늘린다.

각 강의를 시작 시간 순서대로 처리하며, 각 강의에 사용할 수 있는 가장 빨리 비는 강의실을 선택하므로 강의실을 불필요하게 늘리지 않는다. 따라서 마지막에 큐에 저장된 강의실 수는 최소다.

## 복잡도

- 시간: O(N log N). 강의를 정렬하고 각 종료 시간을 우선순위 큐에서 처리한다.
- 공간: O(N). 강의와 강의실 종료 시간을 저장한다.

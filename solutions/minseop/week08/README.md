# BOJ 2212. 센서

- 문제 안내: [8주차 공통 문제 문서](../../../problems/week08/README.md)
- 백준 문제 주소: https://www.acmicpc.net/problem/2212
- 난이도: Gold V
- 구현 언어: C++17

## 1. 처음 확인한 조건

센서는 최대 10,000개이고 집중국은 최대 1,000개입니다. 모든 센서가 적어도 하나의 수신 구간에 포함되도록 하면서 구간 길이의 합을 최소화합니다. 센서 좌표는 중복될 수 있고 수신 구간의 길이는 0일 수 있습니다.

## 2. 단순한 풀이가 비효율적인 이유

정렬한 센서를 그룹으로 나누는 모든 경계 조합을 검사하면 경우의 수가 커집니다. 구간을 나눌 때마다 어떤 거리가 합계에서 빠지는지 살펴보면 모든 조합을 검사할 필요가 없습니다.

## 3. 선택한 알고리즘과 핵심 아이디어

센서 좌표를 오름차순 정렬하고 인접한 센서 사이의 간격을 구합니다. 간격을 오름차순으로 정렬해 가장 작은 `N - K`개의 합을 구합니다. 집중국 수가 센서 수 이상이면 반복문을 실행하지 않아 결과는 0입니다.

## 4. 알고리즘이 올바른 이유

한 그룹의 수신 구간 길이는 그 그룹에서 가장 오른쪽 센서와 가장 왼쪽 센서의 좌표 차이이며, 이는 그룹 내부 인접 간격의 합입니다. 전체를 한 그룹으로 보면 모든 인접 간격의 합이 비용입니다. 그룹 경계를 하나 추가하면 그 경계의 간격이 비용에서 빠집니다. 최대 `K`개 그룹을 만들 수 있으므로 가장 큰 간격부터 최대 `K - 1`개를 제외하면 비용이 최소가 됩니다. 좌표가 같아 간격이 0인 경우에도 같은 논리가 적용됩니다.

## 5. 시간·공간 복잡도

좌표와 간격을 정렬하므로 시간 복잡도는 `O(N log N)`이고, 좌표와 간격을 저장하는 공간 복잡도는 `O(N)`입니다.

## 6. 구현 시 주의할 경계 조건

- `K ≥ N`이면 각 센서를 길이 0인 구간에 포함할 수 있어 답은 0입니다.
- 좌표가 중복되면 인접 간격은 0입니다.
- `K = 1`이면 가장 왼쪽부터 가장 오른쪽까지의 길이가 답입니다.
- 센서가 하나인 경우에도 답은 0입니다.

## 7. 테스트 결과

C++17로 경고 옵션을 켜고 컴파일했습니다. 백준 제출과 정답 판정은 확인하지 않았습니다.

- 공통 문서 예제 → `3`
- 센서 하나 → `0`, 센서 좌표가 모두 같은 경우 → `0`
- 센서 `-5, 0, 10`과 `K = 5` → `0`, `K = 1` → `15`
- 소규모 무작위 입력 200개를 모든 그룹 경계를 열거하는 기준 풀이와 비교해 일치했습니다.

## 8. 학습 포인트

구간을 나누는 문제를 인접한 값 사이의 간격 선택 문제로 바꾸면 탐욕적 선택 기준을 쉽게 찾을 수 있습니다.

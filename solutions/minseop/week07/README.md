# BOJ 11000. 강의실 배정

- 문제 안내: [7주차 공통 문제 문서](../../../problems/week07/README.md)
- 백준 문제 주소: https://www.acmicpc.net/problem/11000
- 난이도: Gold V
- 구현 언어: C++17

## 1. 처음 확인한 조건

모든 강의를 진행해야 하며, 한 강의실에서 진행하는 강의는 시간이 겹치면 안 됩니다. 앞 강의의 종료 시간과 다음 강의의 시작 시간이 같으면 같은 강의실을 사용할 수 있습니다.

## 2. 단순한 풀이가 비효율적인 이유

각 강의를 배정할 때마다 모든 강의실의 종료 시간을 확인하면 강의가 최대 200,000개일 때 최악의 경우 `O(N²)`이 걸립니다. 가장 빨리 끝나는 강의실을 빠르게 찾을 수 있어야 합니다.

## 3. 선택한 알고리즘과 핵심 아이디어

강의를 시작 시간 순으로 정렬합니다. 최소 힙에는 각 강의실에 마지막으로 배정된 강의의 종료 시간을 저장합니다. 새 강의가 시작할 때 가장 빠른 종료 시간이 시작 시간 이하라면 해당 강의실을 재사용하고, 그렇지 않으면 새 강의실을 추가합니다. 새 강의의 종료 시간을 힙에 넣고 모든 강의를 처리한 뒤 힙의 크기를 출력합니다.

## 4. 알고리즘이 올바른 이유

가장 빨리 끝나는 강의실도 새 강의가 시작할 때까지 비지 않는다면 다른 강의실도 모두 사용할 수 없으므로 새 강의실이 반드시 필요합니다. 반대로 가장 빨리 끝나는 강의실이 비어 있다면 이를 재사용해 추가 강의실 없이 현재 강의를 배정할 수 있습니다. 시작 시간 순서로 처리하므로 이 선택은 이후 강의의 배정을 방해하지 않습니다. 따라서 새 강의실이 필요한 경우에만 추가하며 최소 개수를 구할 수 있습니다.

## 5. 시간·공간 복잡도

강의 정렬과 강의별 힙 연산에 `O(N log N)`이 걸립니다. 강의와 힙을 저장하는 공간은 `O(N)`입니다.

## 6. 구현 시 주의할 경계 조건

- 종료 시간과 시작 시간이 같아도 강의실을 재사용합니다.
- 동시에 시작하는 강의는 각각 강의실이 필요합니다.
- 강의가 하나뿐이면 답은 1입니다.
- 힙은 현재 사용 중인 강의만이 아니라 각 강의실에 마지막으로 배정된 강의의 종료 시간을 보관합니다. 따라서 한 강의에 재사용할 강의실 하나만 꺼냅니다.

## 7. 테스트 결과

C++17 경고 옵션으로 컴파일하고 예제, 경계 사례와 무작위 입력을 독립적인 동시 진행 강의 수 계산 결과와 비교했습니다. 백준 제출과 정답 판정은 확인하지 않았습니다.

## 8. 학습 포인트

가장 먼저 비는 강의실을 확인하면 모든 강의실을 매번 살펴볼 필요가 없습니다. 종료와 시작이 같은 시각일 때 재사용이 가능하다는 조건도 부등호에 반영해야 합니다.

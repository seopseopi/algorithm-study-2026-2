# 7주차 · BOJ 11000 강의실 배정 (Gold V)

- 언어: C++17
- 코드: [BOJ_11000.cpp](BOJ_11000.cpp)
- 핵심 기법: 정렬, 탐욕적 알고리즘, 우선순위 큐(최소 힙)

## 문제 분석

강의 `N`개가 주어질 때, **모든 강의를 진행하기 위해 필요한 강의실의 최소 개수**를 구해야 합니다.

- 한 강의실에서는 동시에 두 강의를 진행할 수 없습니다.
- 앞 강의가 끝나는 시각에 다음 강의를 바로 시작할 수 있습니다.
- `N ≤ 200,000`이라 가능한 배정을 모두 확인하는 방법은 불가능합니다.

### 4주차 회의실 배정과의 차이

| 구분 | 4주차 회의실 배정 | 7주차 강의실 배정 |
| --- | --- | --- |
| 목표 | 한 방에서 진행할 수 있는 **회의 수의 최대** | 모든 강의를 진행할 **강의실 수의 최소** |
| 선택 | 일부만 고른다 (나머지는 버림) | 전부 배정한다 |
| 정렬 기준 | 종료 시간 | 시작 시간 |
| 핵심 자료구조 | 정렬만 사용 | 우선순위 큐 |

같은 시간 배정 문제여도 "활동을 몇 개 고를 수 있나"를 묻는지, "공간이 몇 개 필요한가"를 묻는지에 따라 풀이 기준이 달라집니다.

## 풀이

### 1. 시작 시간 순으로 정렬

강의를 시작 시간 오름차순으로 정렬하고 하나씩 배정합니다. 이렇게 하면 현재 강의를 배정할 때 이미 시작한 강의들만 고려하면 됩니다.

### 2. 최소 힙에 강의실별 종료 시간 저장

각 강의실에서 마지막으로 진행한 강의의 **종료 시간**을 최소 힙에 넣습니다. 힙의 top이 **가장 빨리 비는 강의실**의 종료 시간입니다.

### 3. 강의 하나씩 배정

현재 강의의 시작 시간을 `start`, 종료 시간을 `end`라고 할 때:

- `top ≤ start`: 가장 빨리 비는 강의실을 재사용할 수 있습니다. top을 꺼내고 `end`를 넣습니다.
- `top > start`: 가장 빨리 끝나는 강의실도 아직 사용 중입니다. 새 강의실이 필요하므로 `end`만 넣습니다.

모든 강의를 처리한 뒤 **힙에 남은 원소 수**가 필요한 강의실 수입니다.

### 이 선택이 올바른 이유

- 가장 빨리 끝나는 강의실을 쓸 수 없다면, 나머지 강의실은 그보다 늦게 끝나므로 어느 것도 쓸 수 없습니다. 이때 새 강의실을 추가하는 것은 **반드시 필요**합니다.
- 쓸 수 있는 강의실이 있다면 가장 빨리 끝나는 강의실을 재사용해 강의실을 늘리지 않고 배정할 수 있습니다. 다른 강의실을 골라도 강의실 수는 같으므로 손해가 없습니다.

따라서 시작 시간 순서대로 반복하면 필요한 경우에만 강의실이 늘어납니다. 결과는 "동시에 진행되는 강의의 최대 개수"와 같습니다.

### 주의한 점

- **등호 포함**: 끝나는 시각에 바로 시작할 수 있으므로 `top < start`가 아니라 `top <= start`로 비교합니다.
- **같은 시각에 시작하는 강의**: 서로 겹치므로 각각 강의실이 필요합니다. (`1~5` 세 개 → 3)
- **강의가 하나뿐인 경우**: 힙에 원소 하나만 남아 `1`이 출력됩니다.

## 예제 따라가기

입력 `(1,3)`, `(2,4)`, `(3,5)` (시작 시간 순 정렬 완료)

| 강의 | 힙 top | 비교 | 동작 | 힙 상태 |
| --- | --- | --- | --- | --- |
| (1, 3) | 없음 | — | 새 강의실 | `{3}` |
| (2, 4) | 3 | 3 ≤ 2 ✗ | 새 강의실 | `{3, 4}` |
| (3, 5) | 3 | 3 ≤ 3 ✓ | 재사용 (3을 꺼내고 5 삽입) | `{4, 5}` |

힙에 2개가 남으므로 답은 **2**입니다.

## 복잡도

- 시간: 정렬 `O(N log N)` + 강의마다 힙 연산 `O(log N)` → `O(N log N)`
- 공간: 강의 정보와 힙 저장 `O(N)`

## 검증

- 예제 입력 → `2` 출력 확인
- 강의가 하나인 경우(`0 1`) → `1`
- 끝나는 시각에 다음 강의가 시작하는 경우(`1 2`, `2 3`) → `1`
- 모든 강의가 같은 시간인 경우(`1 5` × 3) → `3`
- 한 강의가 길고 짧은 강의들이 그 안에서 이어지는 경우(`1 10`, `2 3`, `3 4`, `4 5`) → `2`
- 무작위 소형 입력 300개를 시간대별로 동시에 진행되는 강의의 최대 개수를 세는 기준 풀이와 비교해 모두 일치
- 최대 크기 입력(`N = 200,000`) → 약 0.05초

# 8주차 · BOJ 2212 센서 (Gold V)

- 언어: C++17
- 코드: [BOJ_2212.cpp](BOJ_2212.cpp)
- 핵심 기법: 정렬, 탐욕적 알고리즘

## 문제 분석

직선 위의 센서 `N`개를 최대 `K`개의 집중국으로 모두 커버하되, **집중국별 수신 구간 길이의 합을 최소화**해야 합니다.

- 센서 좌표는 순서 없이 주어지고, 같은 좌표에 여러 센서가 있을 수 있습니다.
- 집중국 하나는 연속된 구간 하나를 담당하므로, 결국 **센서를 최대 `K`개의 연속된 그룹으로 나누는 문제**입니다.
- 집중국의 위치를 직접 정하는 대신, **어디서 그룹을 끊을지**만 정하면 됩니다.

## 핵심 아이디어: 간격을 고르는 문제로 바꾸기

센서를 좌표순으로 정렬하면 한 그룹의 수신 구간 길이는 `(그룹의 가장 오른쪽 센서) − (가장 왼쪽 센서)`이고, 이는 **그룹 안에 있는 인접 간격의 합**과 같습니다.

따라서

```
전체 길이(= 가장 오른쪽 − 가장 왼쪽) = 모든 인접 간격의 합
```

이고, 그룹을 나누면 **경계가 된 간격만 합에서 빠집니다.** 집중국이 `K`개면 경계를 최대 `K − 1`개 만들 수 있으므로

```
답 = (모든 인접 간격의 합) − (가장 큰 간격 K − 1개의 합)
```

입니다.

### 최적인 이유

경계로 고른 간격은 정답에서 **제외되는 길이**입니다. 같은 개수(`K − 1`개)를 제외한다면 가장 큰 값들을 제외해야 남는 합이 가장 작습니다. 경계 중 하나를 더 작은 간격으로 바꾸면 제외되는 길이가 줄어 합이 늘어나므로, 큰 간격부터 끊는 선택은 항상 최적해에 포함됩니다. 또 경계를 많이 쓸수록(`K − 1`개를 모두 쓸수록) 합이 줄어들기만 하므로 가능한 만큼 쓰는 것이 맞습니다.

## 풀이

1. 센서 좌표를 오름차순으로 정렬합니다.
2. 인접한 센서 사이의 간격을 모두 구합니다. (`N − 1`개, 같은 좌표면 0)
3. 간격을 오름차순으로 정렬합니다.
4. 가장 큰 `K − 1`개를 제외한 나머지 간격을 모두 더합니다.

### 주의한 점

- **`K ≥ N`인 경우**: 센서마다 길이 0인 구간을 둘 수 있으므로 정렬 없이 `0`을 출력합니다. 이 처리가 없으면 `K − 1`이 간격 개수(`N − 1`)보다 커져 반복 범위가 음수가 됩니다.
- **같은 좌표의 센서**: 간격이 0이 되며, 그대로 정렬·합산에 포함해도 결과에 문제가 없습니다.
- **`K = 1`**: 제외할 간격이 없으므로 가장 오른쪽 좌표 − 가장 왼쪽 좌표가 답입니다.
- **센서가 하나뿐인 경우**: `K ≥ N`에 해당해 `0`이 출력됩니다.

## 예제 따라가기

입력 `1 2 8 9 10`, `K = 2` (이미 정렬된 상태)

| 단계 | 값 |
| --- | --- |
| 인접 간격 | `1, 6, 1, 1` |
| 오름차순 정렬 | `1, 1, 1, 6` |
| 제외할 간격 (`K − 1 = 1`개) | 가장 큰 `6` |
| 남은 간격의 합 | `1 + 1 + 1 = 3` |

`6`(2와 8 사이)에서 끊으면 `[1, 2]`와 `[8, 10]`으로 나뉘어 `1 + 2 = 3`이 됩니다. 답은 **3**입니다.

## 복잡도

- 시간: 좌표 정렬 `O(N log N)` + 간격 정렬 `O(N log N)` → `O(N log N)`
- 공간: 좌표와 간격 저장 `O(N)`

## 검증

- 예제 입력 → `3` 출력 확인
- 집중국이 하나인 경우(`1 2 8 9 10`, `K = 1`) → `9`
- 센서가 하나뿐인 경우 → `0`
- 집중국이 센서보다 많은 경우(`K = 5`, 센서 3개) → `0`
- 모든 센서가 같은 좌표인 경우(`5 5 5 5`) → `0`
- 정렬되지 않은 입력(`10 1 9 2 8 3`, `K = 3`) → `3`
- 무작위 소형 입력 200개를 가능한 그룹 경계를 모두 확인하는 기준 풀이와 비교해 모두 일치
- 최대 크기 입력(`N = 10,000`, `K = 1,000`) → 약 0.003초
